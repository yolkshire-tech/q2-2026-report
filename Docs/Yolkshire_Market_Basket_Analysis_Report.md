## Appendix: Methodology Notes

### Data Sources

- **Menu_Prices_Costs**: 178 items with selling prices and food cost percentages
- **Sales_By_Items**: Q2 2026 aggregated sales by item (filtered for Sale invoices, Item type)
- **Cleaned_Transactions**: 40,193 transactions with session, channel, and branch data

### Margin Calculation

Margin % = 100% - Food Cost % Blended Combo Margin = Weighted average of component margins by price

### Combo Viability Criteria

1. **Margin Threshold**: Minimum 75% blended margin
2. **Anchor Requirement**: Lead item should have 500+ Q2 sales
3. **Menu Availability**: All items must be on active menu
4. **Session Fit**: Combo should match anchor item’s peak session

### Limitations

- True market basket analysis (items frequently purchased together) requires invoice-level item detail, which is aggregated in current dataset
- Recommendations based on:
  - High-margin items (≥75%) with low relative sales volume
  - Top-selling anchor items that drive order frequency
  - Session-based consumption patterns
  - Category complementarity (Mains + Beverages, Mains + Sides)
